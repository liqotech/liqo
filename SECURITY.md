# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously.
If you discover a security vulnerability, please follow the following guidelines.

### How to Report

**Do not** disclose vulnerabilities through public GitHub issues, pull requests, or discussions.
Instead, please report them privately using the **Private Vulnerability Reporting** function in GitHub: go to the **Security** tab of our repository, click on **Advisories**, and select **Report a vulnerability** ([direct link](https://github.com/liqotech/liqo/security/)).

### What to Include in Your Report

Please provide as much of the following information as possible to help us reproduce and fix the issue quickly, such as:

* **Type of Issue**: E.g., SQL injection, cross-site scripting (XSS), buffer overflow, remote code execution.
* **Affected Source Code**: Full file paths, branch, commit, or tag.
* **Step-by-Step Instructions**: A clear proof-of-concept (PoC) or script to reproduce the vulnerability.
* **Public Disclosure Status**: Let us know if you plan to make the issue public or if it has already been discussed elsewhere.

### What to Expect

* **Acknowledgment**: We will review your report and send an initial response **as soon as possible**.
* **Updates**: We will keep you informed as we investigate, patch, and release a fix for the vulnerability.
* **Credit**: Once fixed, we will publicly credit you in our release notes (unless you prefer to remain anonymous).
